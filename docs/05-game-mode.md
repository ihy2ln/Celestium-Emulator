# Game mode

Game mode lets you play Android games with a keyboard, mouse or controller. Open it with **🎮 Game mode** on Overview, from the tray, or with **Ctrl+G**. The device needs its window, so background mode must be off.

A toolbar appears above the phone:

| Button | What it does |
|---|---|
| ✎ Edit | Map keys (see below). Press ✓ Done to save. |
| Hints | Show or hide the key labels on the screen |
| ⇄ Sync | Mirror everything to your other running devices |
| ⏺ | Record a macro. Press ■ to stop. |
| ▶ | Play the macro. Right-click to loop it (▶∞). |
| ✕ | Leave game mode |

While game mode is on:

- **Mapped keys** tap their spot on the screen. Holding the key holds your finger down.
- **Unmapped keys** still work as a keyboard: letters type into text boxes, Enter, Backspace and the arrow keys work, and **Esc is Back**.
- **The mouse** taps and drags like a finger.

## Mapping keys

Press **✎ Edit**. The screen dims and your controls appear.

- **Right-click empty space** to add:
  - **Button:** press the key and/or the controller button it should use.
  - **Movement joystick:** WASD by default, plus the controller's left stick.
  - **Camera stick:** the controller's right stick.
- **Drag** a control to move it.
- **Scroll** over a joystick to make it bigger or smaller.
- **Right-click a control** to:
  - change its key
  - turn on **Turbo** (taps repeatedly while held)
  - pick which controller stick drives it
  - delete it

Press **✓ Done** to save. Each game keeps its own key map, chosen automatically by whichever app is in front. Right-click empty space and choose **Save as default for all apps** to make a map the starting point for games that don't have one yet.

Make a key map in the same orientation you'll play in. Landscape games should be mapped while the device window is in landscape.

## Controllers

Any Xbox-compatible (XInput) controller works. The buttons are A, B, X, Y, LB, RB, LT, RT, the D-pad, Start, Back and both stick clicks. The left stick drives the movement joystick and the right stick drives the camera stick. Controller input is only used while the game or its toolbar is in front.

## Macros

Press **⏺** and play normally: taps, keys and controller input are all recorded with their timing. Press **■** to stop. The macro is saved for the current game. Press **▶** to replay it once, or right-click ▶ to loop until you press ■.

## Multi-device sync

Press **⇄ Sync** to mirror every touch and keystroke from this device to all your other running devices at the same time. Screens of different sizes line up automatically. This is useful for testing an app on several phones at once.
